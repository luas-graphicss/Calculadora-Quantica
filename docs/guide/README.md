# Guia da Calculadora Quântica

Para quem vai calcular com a versão 1.0.0rc1, não para quem vai mexer no código. Os exemplos usam os arquivos de `reference_cases/`, que acompanham a distribuição.

- `installation.md`: instalar sem rede, conferir a instalação, atualizar e remover.
- `first-calculation.md`: do poço de 1 nm à resposta conferida, pela bancada e pelo terminal.
- `../notation/grammar.md`: como escrever um enunciado em texto ou em LaTeX.
- `methods.md`: o método de cada ficha, como ele é verificado e contra o que foi homologado.
- `conventions.md`: unidades, constantes, arredondamento, incerteza e o vocabulário dos resultados.
- `operational-limits.md`: tamanhos aceitos, tempo, memória e o que fica fora do escopo.
- `diagnostics.md`: recusas, códigos de saída e o que fazer em cada falha.
- `reproduction.md`: pacote de reprodução, comparação entre execuções, cópia e restauração do histórico.
